# School Management System

## About
A web application for managing student records and generating student ID cards and Transfer Certificates.

## Features
- Add, view, edit, and search student records
- Upload student photos
- Preview and download student ID cards as PDFs
- Generate Transfer Certificates as PDFs
- Manage school details
- Support Classes 8, 9, and 10, with room to add more classes

## Technologies
- Python
- Flask
- SQLite
- HTML and CSS
- JavaScript
- ReportLab

## How to Run
1. Install Python.
2. Install the required packages:
   `python -m pip install -r requirements.txt`
3. Run the application:
   `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.
